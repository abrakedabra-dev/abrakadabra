# 🪄 Абракадабра

https://github.com/user-attachments/assets/881b1825-73d1-4250-866d-d5b8e63d56f6

Голосовой помощник для macOS, который работает **полностью на твоём компьютере**. Скажи «Абракадабра, Safari», и Safari откроется. Без облака, без подписки, без Siri.

*Offline Russian voice assistant for macOS (Apple Silicon).*

---

## Что умеет

Все команды говорятся после слова **«Абракадабра»**:

| Что | Как сказать |
|---|---|
| Открыть приложение | «Safari», «заметки», «открой Telegram» |
| Закрыть | «закрыть Safari» · просто «закрыть» закрывает последнее открытое |
| Поиск | «найди на ютубе обзор M5» · «найди рецепт блинов» |
| Папки | «загрузки», «документы», «рабочий стол» |
| Звук | «громче», «тише», «громкость 40», «выключи звук» |
| Экран | «ярче», «темнее», «заблокируй экран», «усыпи мак» |
| Время | «который час», «какое сегодня число» |
| Таймеры | «таймер на 10 минут», «напомни через 20 минут выключить чайник», «отмени таймер» |
| Погода | «какая погода» |
| Музыка | «пауза», «дальше», «предыдущий трек» (Spotify и Музыка) |
| Прочее | «сделай скриншот», «напиши Привет!», «смени голос», «выключись» |

**Быстрый режим:** «Абракадабра, быстрый режим». После этого команды говорятся без имени. Выход: «хватит». Сам выключается через 3 минуты тишины.

## Как это устроено

| Часть | Технология | Где работает |
|---|---|---|
| Слово-активатор | [Vosk](https://alphacephei.com/vosk/) | на компьютере |
| Распознавание команд | [mlx-whisper](https://github.com/ml-explore/mlx-examples) на чипе Apple | на компьютере |
| Голос | [Piper](https://github.com/OHF-Voice/piper1-gpl) | на компьютере |

Звук с микрофона **никуда не отправляется**. В интернет помощник выходит только при первой загрузке моделей и для команды «погода» (сервис wttr.in).

## Требования

- Mac с чипом Apple (M1 и новее)
- macOS 14 или новее
- ~2 ГБ на диске, ~1.5 ГБ оперативной памяти во время работы

## Установка

Нужен [Homebrew](https://brew.sh).

```bash
# 1. Инструменты
brew install git uv

# 2. Код
git clone https://github.com/abrakedabra-dev/abrakadabra.git ~/abrakadabra
cd ~/abrakadabra
uv sync

# 3. Голоса (~120 МБ)
zsh download_voices.sh

# 4. Первый запуск из терминала (скачает модели распознавания ~500 МБ)
uv run abra.py
```

Когда услышишь «Готова к работе», скажи «Абракадабра, Safari». macOS спросит доступ к микрофону, разреши.

### Работа в фоне, без окна терминала

```bash
zsh install_app.sh
open ~/Applications/Abrakadabra.app
```

Автозапуск: Системные настройки → Основные → Объекты входа → «+» → `~/Applications/Abrakadabra.app`.

- Лог: `tail -f ~/abrakadabra/abra.log`
- Остановить: `~/abrakadabra/stop.sh` или голосом «Абракадабра, выключись»
- Если поменять `abra.py`, помощник сам перезапустится с новой версией.

### Разрешения macOS

Каждое разрешение спрашивается при первом использовании функции, которой оно нужно:

| Разрешение | Для чего |
|---|---|
| Микрофон | слышать команды |
| Универсальный доступ | яркость, диктовка |
| Запись экрана | скриншоты |
| Автоматизация | закрытие приложений, музыка |

## Настройка

Всё в начале `abra.py`:
- `ALIASES`: свои названия приложений («телега» → Telegram)
- `SITES`, `FOLDERS`: сайты и папки
- `WAKE_THRESHOLD`: чувствительность к слову «Абракадабра»
- `SILENCE_END_SEC`: пауза, после которой команда считается законченной

## Известные ограничения

- Только русский язык.
- Может проснуться от слова «Абракадабра» в видео или в разговоре рядом.
- Яркость работает не на всех Mac.
- Музыкой управляет только в Spotify и приложении «Музыка», не в YouTube.

## Лицензия

Код распространяется под **GPL-3.0**, потому что использует Piper (GPL-3.0). Модели голосов скачиваются отдельно, у каждой своя лицензия: смотри `MODEL_CARD` на странице голоса в [piper-voices](https://huggingface.co/rhasspy/piper-voices).
